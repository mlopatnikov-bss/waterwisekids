WaterWiseKids Open Data

Read-only JSON datasets and public MCP tools

Beta means constrained claims. These files expose source-linked records, not hidden confidence. Price data returns observations rather than a benchmark; level matches are not placement; law summaries are not legal advice; access diagnostics are not rankings.

The API is static, cacheable JSON with stable versioned paths. It requires no key and performs no write operation. Use the machine-readable catalog to discover datasets and their limitations.

Public MCP server

Connect an MCP Streamable HTTP client to https://mcp.waterwisekids.com/mcp. The public beta requires no key and exposes only the four read-only tools below. It has no database or write credentials. Its health endpoint is mcp.waterwisekids.com/health.

Transport limits: requests are capped at 64 KiB; invalid hosts and browser origins fail closed; and layered burst/rate controls protect the public service. Dataset caveats remain part of every tool response.

ToolBehavior and guardrail
find_swim_schoolsReturns source-checked directory locations by ZIP-centroid distance and disclosed filters. Results are not a complete market census.
get_price_benchmarkReturns “not publishable” while price sampling gates fail; it may return underlying state observations without calling them a benchmark.
translate_levelReturns neutral-band overlaps and requires a receiving-school assessment.
get_state_lawsReturns verified pilot modules or an explicit unpublished status plus the federal life-jacket baseline.
