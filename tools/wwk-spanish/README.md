# WWK Spanish publication gate

The audit recommends a Spanish layer reviewed by a native speaker. Machine
translation may create an internal draft, but it must not be indexed, linked
with `hreflang`, or described as reviewed until a named native-speaking reviewer
approves the exact source and translation versions.

The queue contains the first 40 decision and safety pages. A `publish_ready`
item requires the public Spanish path, reviewer name, review timestamp, and
SHA-256 hashes of both versions. If the English source changes, the translation
returns to review. Medical, legal and tax guidance also needs the same subject-
matter source checks as the English page.
