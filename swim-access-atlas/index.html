Swim Access Atlas Foundation

Three-county data coverage diagnostic—not an access ranking

Data coverage diagnostic — not an access score or swim-desert ranking The current provider and pool files are not complete inventories. A low WWK count cannot show that families lack lessons or pools.
Why publish this? It makes the missing data visible before WWK produces thousands of county pages or labels a community. The pilot joins Census youth population with locations currently present in the WaterWiseKids school directory and starting pool list. Those WWK lists are not complete inventories, so the counts measure WWK data coverage, not all real-world access.

Why no access score appears

A defensible access measure needs verified year-round providers, actual travel time, prices, scholarships, and a documented completeness audit. These gates have not passed:

  • Not passed: all providers geocoded
  • Not passed: provider inventory sample audited
  • Not passed: year round access verified
  • Not passed: drive time matrix built
  • Not passed: price coverage sufficient
  • Not passed: scholarship coverage sufficient
  • Not passed: small number suppression implemented

No county page is generated until its minimum data threshold passes. Drowning-rate fields will also follow CDC small-number suppression rules before publication.

Methods and sources

  • 2024 ACS 5-Year Table B09001, field B09001_E001 for population under 18. The source file hash is recorded in the dataset.
  • 2020 Census ZCTA-to-County relationship file. Each ZCTA is assigned to the county containing its largest land-area share; a ZCTA is only a ZIP approximation.
  • The WWK school directory and Find a Pool list are starting datasets, not provider censuses. Duplicate street address plus ZIP is counted once.

Ownership and sampling bias

WaterWiseKids and British Swim School businesses serving the Jersey Shore and Northwest Philadelphia share common ownership. That relationship is especially material in this pilot because several observed listings are affiliated schools. See the full ownership disclosure. Affiliated locations receive no score or preferential treatment; no score is published at all in this pilot.
